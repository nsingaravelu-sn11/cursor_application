This page is the visual shell for the demo. Live CPU, memory, network, disk, and port figures will appear here after servers are connected.

Status labels

Each state uses a text label with its color, so the meaning stays clear on its own.

  • Healthy

    The latest poll succeeded, and CPU and memory are both under 80%.

  • Warning

    CPU or memory is at least 80% and under 95%. The label names the resource.

  • Critical

    CPU or memory is at least 95%. The more severe resource sets the label.

  • Unreachable

    The latest poll did not return a sample. The card keeps the plain-language cause.
